# Nova · Заметки

Веб-приложение для заметок и напоминаний: разделы, заметки с текстом, привязанные к ним напоминания (дата и время).
Работает в браузере, устанавливается на главный экран телефона, хранит данные на устройстве. Без сборки и зависимостей.

## Структура

```
index.html            разметка и подключение стилей/скриптов
manifest.webmanifest  данные для установки на главный экран
sw.js                 service worker (офлайн-кэш)
css/
  base.css            переменные, сброс, типографика, каркас
  components.css      карточки, чипы, нижняя панель
  sheet.css           всплывающие окна, формы, ползунок
js/
  main.js             точка входа, обработка кликов (data-act)
  config.js           константы: ключи хранилища, палитра
  store.js            данные и localStorage (разделы, заметки, напоминания)
  views.js            отрисовка экранов
  sheets.js           всплывающие окна и формы
  utils.js            вспомогательные функции
  icons.js            SVG-иконки
  pwa.js              регистрация service worker, подсказка про установку
icons/                иконки приложения
```

## Запуск локально

Модули ES не работают при открытии файла двойным щелчком, нужен локальный сервер:

```
python3 -m http.server 8000
```

Откройте http://localhost:8000

## Публикация на GitHub Pages

Settings → Pages → Source: Deploy from a branch → ветка `main`, папка `/ (root)`.
Адрес: `https://<логин>.github.io/<репозиторий>/`

После изменений файлов увеличьте `CACHE` в `sw.js` (например, `nova-v2`), чтобы телефоны подтянули новую версию.

## Формат данных

В `localStorage` под ключом `nova-v2` лежит JSON: `fo` (разделы), `no` (заметки), `re` (напоминания).
Данные привязаны к адресу сайта и хранятся только на устройстве.
